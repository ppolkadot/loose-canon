## What each candidate needs (the same dated record as the portals)

For every brokerage site the owner names, record: current terms of use and `robots.txt`; any public
API, XML/JSON feed or data licence; static HTML vs JavaScript rendering (and whether a JSON endpoint
is *permitted*); login or anti-bot walls (never bypassed); rate-limit guidance; rights over photos
and text; stability of listing URLs/ids; whether the price field is structured and whether "ágio"
listings are labelled; and the brokerage's own contact policy.

A brokerage qualifies only if its published terms (or a written authorization) allow automated
collection for this use. Small sites often publish no terms at all; absence of a prohibition is
**not** permission, so such a site would need the brokerage's written consent.

that written permission is straightforward), or confirms a feed/agreement. Then this record is
completed and, if at least one passes review, the first real adapter can be built against it.
